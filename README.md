## Featured projects

### [AI-Powered Code Reviewer](https://github.com/Kartiksh123/AI-POWERED-CODE-REVIEWEE)

Analyze code with Google Gemini through a Streamlit interface, ask follow-up questions, and export an HTML review report. The project makes AI-assisted feedback easier to explore alongside the source code.

`Python` `Streamlit` `Google Gemini API`

### [ScrollBite](https://github.com/Kartiksh123/ScrollBite)

A full-stack food-discovery app for short cooking and restaurant videos. Users can browse, like, save, and comment on reels; food partners can create accounts and share videos.

`React` `JavaScript` `Node.js` `Express` `MongoDB`  |  [Live demo](https://scrollbite-kartiksh123-55ct.onrender.com/)

### [Food Delivery Time Predictor](https://github.com/Kartiksh123/Food-Delivery-Predictor)

A Streamlit app that estimates delivery time from factors such as distance, traffic, weather, and courier experience using Linear Regression. The repository does not include model-evaluation results, so no performance figures are claimed.

`Python` `Streamlit` `pandas` `scikit-learn`

### [Heart Stroke Predictor](https://github.com/Kartiksh123/heart-stroke-predictor)

An educational Streamlit machine-learning app using K-Nearest Neighbors. The current model predicts a heart-disease label; it does not predict stroke and is not a medical diagnostic tool.

`Python` `Streamlit` `scikit-learn` `pandas`
